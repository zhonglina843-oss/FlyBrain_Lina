# FlyBrain 实验方案 v0.1

## 研究问题

固定真实连接拓扑后，逃逸方向选择的性能有多少来自拓扑本身，又有多少依赖动力学参数适配和在线可塑性？

这里的“推理”限定为可测量的快速感觉-运动规划，不把闭环控制结果外推为通用推理能力。

## 可证伪假设

- H1（结构）：真实连接子图在不训练拓扑时，优于保持度分布的随机重连图。
- H2（少参数适配）：只拟合细胞类型 gain，就能显著改善方向选择和反应延迟。
- H3（状态依赖）：加入身体初始姿态后，模型输出会产生与 Card & Dickinson 行为结果同方向的条件变化。
- H4（持续适应）：局部可塑性比全网更新产生更少的旧条件性能退化。

## 阶段 0：数据和命名审计

目标：先确定可用数据，而不是先写模拟器。

1. 用脚本列出 neuPrint 当前数据集和版本。
2. 分别记录 FlyWire/FAFB、hemibrain、MaleCNS 的性别、覆盖范围、版本、神经元数、突触阈值和许可。
3. 在目标数据集中搜索 looming、descending 和 motor 相关类型，并人工核对论文与数据注释。
4. 生成 `data/processed/candidate_neurons.csv` 和 `candidate_edges.csv`。

停止条件：候选细胞类型或输入输出映射无法由数据注释及论文共同支持时，不进入动力学实验。

## 阶段 1：纯拓扑基线

输入是按方位编码的 looming 刺激；输出先采用下降神经元群的活动读出，不直接声称为腿部动作。

对照组：

- 真实子图；
- 保持节点数和边数的随机图；
- 保持入度/出度分布的随机重连图；
- 打乱神经递质符号或细胞类型标签；
- 移除候选关键通路的消融图。

指标：方向角误差、正确象限率、首次越阈时间、扰动鲁棒性、跨初始姿态的一致性。

## 阶段 2：动力学与训练预算

使用同一拓扑依次比较：

| 条件 | 可学习项 | 目的 |
|---|---|---|
| A | 无 | 测试结构本身 |
| B | 全局少量时间常数/阈值 | 测试通用动力学校准 |
| C | per-cell-type gain | 测试少参数适配 |
| D | 局部候选突触可塑性 | 测试在线适应 |
| E | 全部边权可训练 | 性能上界，不作为生物合理主张 |

所有条件使用相同的训练/验证刺激划分，并同时报告参数量和优化步数。禁止把“没有反向传播”写成“没有训练”。

## 阶段 3：Card & Dickinson 行为约束

任务至少包含威胁方位、初始身体朝向和初始腿/质心状态。模拟应预测起跳前的姿态调整及最终逃逸方向，而不仅是二元“跳/不跳”。关键观察窗口以论文报告的起跳前约 200 ms 为参照，但仿真时间常数必须单独校准。

## 最小交付物

- 数据版本与许可清单；
- 候选神经元和边表；
- 可重放的查询命令；
- 五个模型条件的统一评估表；
- 拓扑随机化和关键节点消融结果；
- 一页结论：哪些结果支持结构先验，哪些仍依赖拟合。

## 主要风险

- 跨数据集复用 body ID 或细胞类型名称；
- 把突触数量直接当作生理权重；
- 把人工输入/输出映射产生的行为归因于 connectome；
- 只和完全随机网络比较，导致基线过弱；
- 用项目演示中的声明代替独立实验验证；
- 雌蝇全脑、半脑和雄蝇 CNS 的差异没有记录。
