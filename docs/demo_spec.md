# 组内演示规格

## 演示要回答什么

演示不是为了证明“果蝇大脑无需训练就会推理”，而是让观众在 3-5 分钟内看到：真实连接组怎样被查询、怎样变成可运行的神经动力学，以及结构先验相对对照组是否有可测量优势。

## 最小可验收版本

### 画面 1：数据来源

显示所用数据集、版本、性别、覆盖范围、候选神经元数和连接数。明确区分 FlyWire FAFB、hemibrain 和 MaleCNS。

### 画面 2：回路

显示 looming 视觉输入、候选视觉投射神经元、下降神经元和运动读出之间的子图。点击节点可显示类型、body ID、上游/下游和连接强度。

### 画面 3：刺激与响应

从左、右、前、后施加扩张视觉刺激，播放神经群活动随时间传播，并输出预测逃逸方向、角误差和首次响应时间。

### 画面 4：对照实验

同一刺激并排比较：

- 真实拓扑，无参数训练；
- 保持度分布的随机重连拓扑；
- 真实拓扑加少量 cell-type gain；
- 关键候选神经元消融。

这一画面是研究价值的核心。只有动画而没有对照，只能算工程展示。

## 完成标准

- 一条命令可启动；
- 固定随机种子后结果可复现；
- 页面或图表能追溯到原始数据版本；
- 不把突触数称为已知生理权重；
- 不把人工指定的感觉/运动映射包装成涌现能力；
- 有真实拓扑、随机重连和消融三类结果。

## 推荐汇报结构

1. 连接组是什么，以及它缺少什么；
2. 我们选择的逃逸行为问题；
3. 数据查询与候选回路；
4. demo；
5. 对照结果；
6. 下一步：全脑仿真、在线可塑性及与 CTM 的比较。
