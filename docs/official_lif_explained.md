# 官方全脑 LIF 仓库及本次链路实验详解

## 1. 这个仓库在实验中的作用

`philshiu/Drosophila_brain_model` 是 Shiu 等人的论文模型代码。它把静态 FlyWire 连接组变成一个可以随时间演化的脉冲神经网络。

仓库提供两类核心材料：

1. `Completeness_783.csv` 和 `Connectivity_783.parquet`：神经元列表与连接表；
2. `model.py`：Brian2 实现的 LIF 神经动力学、人工激活、沉默和 spike 记录。

它不提供眼睛、身体、肌肉、游戏动作或自然行为。它回答的是：**当指定神经元被人工激活时，基于连接组和一套统一 LIF 参数，活动会传播到哪些神经元？**

## 2. 连接组数据是什么

可以把连接组看成一个有向加权图：

- 节点：神经元；
- 有向边：从突触前神经元指向突触后神经元；
- `Connectivity`：该神经元对之间的突触计数；
- `Excitatory`：根据递质预测赋予的正负符号；
- `Excitatory x Connectivity`：官方模型实际使用的有符号连接数量。

这张图本身没有时间，也不会自动产生 spike。必须增加神经动力学才能运行。

## 3. 一跳、两跳是什么意思

这里的“跳”是图上的连接距离，不是仿真时间步。

```text
A -> B -> C
```

- B 是 A 的一跳下游：从 A 沿一条边到达；
- C 是 A 的两跳下游：需要经过 A -> B 和 B -> C 两条边；
- 如果 A 直接连到 C，那么 C 同时也是 A 的一跳下游。

本实验从 LC4/LPLC2 出发：

- 一跳：所有直接收到 LC4/LPLC2 突触的神经元；
- 两跳：再加入所有直接收到“一跳神经元”突触的神经元。

真实脑图高度互联，所以范围扩张非常快：全部 314 个 LC4/LPLC2 候选的一跳子图约 10,693 个神经元，两跳已达到约 94,968 个。这种现象称为图搜索的组合扩张，也是全脑 Brian2 对象非常重的原因之一。

## 4. 什么是诱导子图

选出一组神经元后，“诱导子图”保留这些神经元之间原本存在的所有边。

本次最终实验没有把 314 个候选全部作为输入，而是：

1. 从官方连接表找到所有 LC4/LPLC2 -> DNp01 直接边；
2. 每种类型选择对 DNp01 直接突触计数最高的 5 个神经元；
3. 加入这 10 个输入的一跳下游；
4. 保留这 1,062 个神经元之间的全部 50,385 条官方边；
5. 将原全脑 index 重新映射为局部连续 index，供官方 `model.py` 建图。

只改变图的范围，不改变 LIF 方程和官方模型参数。

## 5. LIF 是什么

LIF 是 Leaky Integrate-and-Fire，中文常译为“漏积分发放”。它用两个核心过程近似神经元。

### 积分和漏电

神经元接收上游突触输入后，膜电位上升；如果一段时间没有新输入，膜电位又逐渐回到静息值。

官方模型的膜电位方程是：

```text
dv/dt = (v0 - v + g) / tau_m
```

- `v`：当前膜电位；
- `v0`：静息电位；
- `g`：当前突触输入；
- `tau_m`：膜时间常数。

`Integrate` 指输入在时间上累积；`Leaky` 指累积不会永久保存，而会衰减。

### 放电和重置

当膜电位超过阈值时，模型记录一个 spike，然后重置膜电位并进入短暂不应期：

```text
if v > v_threshold:
    emit spike
    v = v_reset
```

官方默认参数包括：

| 参数 | 数值 | 含义 |
|---|---:|---|
| 静息电位 | -52 mV | 无输入时趋近的膜电位 |
| 放电阈值 | -45 mV | 超过后记录 spike |
| 膜时间常数 | 20 ms | 膜电位变化时间尺度 |
| 突触衰减 | 5 ms | 突触输入逐渐消失的速度 |
| 不应期 | 2.2 ms | 放电后暂时不能再次放电 |
| 突触延迟 | 1.8 ms | spike 到下游输入之间的延迟 |
| 单位突触权重 | 0.275 mV | 每个连接计数的基础电位影响 |

## 6. 人工输入是什么

官方模型用 `PoissonInput` 模拟“指定神经元以某个平均频率被外部激活”。本次给 5 个 LC4 和 5 个 LPLC2 设置 150 Hz、持续 100 ms。

Poisson 输入具有随机性：150 Hz 是平均频率，不表示每 6.67 ms 精确发放一次。因此单次试验可用于验证链路，但不能估计稳定效应或误差范围。

它更像计算机中的光遗传学刺激，不是把真实 looming 视频送进眼睛。

## 7. 官方代码和我们的代码如何分工

### 官方代码负责

- `NeuronGroup` 和 LIF 方程；
- `Synapses` 和连接权重；
- 突触延迟；
- `PoissonInput`；
- 神经元沉默；
- `SpikeMonitor`；
- `Network.run()`；
- spike 结果生成。

### 我们的包装代码负责

- 从官方表选择 LC4、LPLC2 和 DNp01；
- 选择固定的 5 + 5 个直接连接输入；
- 抽取一跳诱导子图；
- 重新编号局部 index；
- 调用官方 `model.run_exp()`；
- 汇总 DNp01 spike 和绘图。

因此准确表述是：**官方连接数据 + 官方 LIF 动力学 + 我们定义的输入选择和局部实验设计。**

## 8. 本次结果说明什么

在一次 100 ms 的人工激活试验中：

- 右侧 DNp01 发放 4 次，首次为 10.5 ms；
- 左侧 DNp01 发放 2 次，首次为 32.3 ms；
- 局部网络共有 39 个神经元产生 spike。

这证明技术链已经跑通：

```text
官方连接表 -> LC4/LPLC2 人工激活 -> 官方 LIF -> DNp01 spike
```

## 9. 本次结果不说明什么

它不能单独证明：

- 真实 looming 视觉一定产生相同输入；
- DNp01 spike 必然导致逃逸；
- 左右差异具有统计稳定性；
- 模型已包含 VNC、肌肉和身体；
- 果蝇无需训练即可完成游戏任务。

此外，选择“对 DNp01 连接最强的输入”适合验证链路，但存在选择偏向，不能用来估计随机 LC4/LPLC2 的平均效应。

## 10. 下一步为什么是 flyvis

当前实验绕过了眼睛，直接人工刺激视觉投射神经元。`flyvis` 补上的是前一段：

```text
视觉影片/自定义刺激 -> 视网膜六角采样 -> 连接组约束视觉网络 -> 视觉神经响应
```

下一步的目标不是立刻接游戏，而是理解：真实视觉输入怎样转换成神经输入，以及固定 connectome 后仍有哪些参数需要训练。
